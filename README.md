# E-Commerce Product Multi-Filter Sidebar

A full-stack starter project for an e-commerce experience with a product listing and a multi-filter sidebar.

## Structure

- client: React + Vite frontend
- server: Express backend API
- shared: reusable types and constants can be added here later

## Run locally

1. Install dependencies: npm install
2. Start both apps: npm run dev
3. Open http://localhost:5173 for the frontend and http://localhost:5000 for the API
